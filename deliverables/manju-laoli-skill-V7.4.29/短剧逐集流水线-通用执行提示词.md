# 短剧逐集流水线・通用执行提示词（可投新智能体）

> 用途：逐集把短剧剧本生成「看板源 md → 投喂看板 html + 画布载荷 json」三件套。
> 通用于：① 已建台账的剧集续跑；② 全新剧本冷启动。
> 铁律：
>
> **只生成文件，禁止提交任何花钱生成（图 / 视频 API）**
>
> ；资产生成前必须先经用户确认 "生成"。



***

## 〇、参数定义（执行前先向用户确认，或按历史沿用）



| 参数     | 说明                                           | 示例                |
| ------ | -------------------------------------------- | ----------------- |
| {剧本路径} | 剧本全集权威源（逐字对稿）                                | `<剧本全集.md 的绝对路径>` |
| {项目名}  | 剧名（用于文件名前缀）                                  | `<剧名>`            |
| {输出目录} | 三件套落盘目录（绝对路径）                                | `<输出目录绝对路径>`      |
| {集号}   | 两位数                                          | `01`、`12`         |
| {技能目录} | 本流水线技能的生效目录（含 scripts\build\_board\_lite.py） | `<技能根目录>`         |

**入口分支判定**：扫 {输出目录} 是否已有 `{项目名}_第NN集_画布载荷.json`——



* **有** → 续集模式：台账自动继承（`--asset-ledger` 指向 {输出目录}），新增资产图号 = 当前最大图号 + 1；

* **无** → 冷启动模式：从第 01 集起，资产图号从 **图 1** 起编，声线锁自拟。

**冷启动必问六锁（禁默认跳过）**：① 题材赛道（决定写实 / 玄幻等分档）② 模型版本（默认 Seedance 2.0）③ 画幅（默认 9:16 竖屏）④ 交付形态（md + 看板 html + 画布 json）⑤ 段缝衔接（末帧定格 / 换机位硬切 / 空镜过渡 / 技巧转场）⑥ 画面风格锁。已建剧集沿用历史锁值，不混档。



***

## 一、读剧本

用 Read 读 {剧本路径}，定位「第 {集号} 集：」到「第 {集号 + 1} 集：」之间段落，**逐字对稿**：人物名单、每句台词、动作 / 道具细节、场次（内外景 / 昼夜）—— 禁止凭印象写分镜。



***

## 二、定资产（复用 vs 新增）



* 角色：名字出现在本集人物名单 → 查台账；已有 → 复用图号 + 声线锁；新角色 → 新增图号（角色四格立绘，声线锁自拟英文标签）。

* 场景：本集场次 → 查台账；新场景 → 新增图号（**母版 + 九宫格两张**：图 N + 图 NB）。

* 道具：承担叙事功能 / 跨镜一致 / 有状态变化的关键道具才建资产；新道具 → 新增图号（道具四格设定图）。

* **新增图号必须顺延，严禁重复 / 跳号**。



***

## 三、写 {项目名}\_第 {集号} 集\_看板源.md

**标题**：`# {项目名} · 第{集号}集 · 投喂看板源`（**不带版本号 / 备注**）

**顶部**：`【画幅】：9:16` + `【模型版本】：Seedance 2.0`

### P2.5・资产出图提示词（每项一段 `### 图N · 名字（类型）` + \`\`\`text 围栏）



* **角色四格立绘**：16:9 整板横版；① 面部特写（唯一清晰脸，五官 10 项逐项锁定）② 正面全身（**无脸**，完整到鞋）③ 90° 侧面全身（无脸）④ 背面全身（无脸）；**全图共 4 格，禁第 5 格、禁砍头、禁 "打马赛克" 表述（写 "无脸"）**；统一端正站立（no pose）；图底设**声纹波形锚（非文字图形）** + **≤8 词英文音色速览标签（图底唯一入图文字）**；围栏外附 ① 完整版 Voice Description（2-4 句英文・不进图）② 速览标签 ③ 图底声纹锚说明；负向词：fifth panel, extra panel, different face, mosaic, pixelated, headless, cropped feet, watermark, logo, extra text, labeled panels, character name。

* **场景母版**：16:9 整板**纯场景无人**；50mm；写清年代 / 地域 / 空间结构 / 固定陈设 / 时段光照；曝光充足、真实材质。

* **场景九宫格**：3×3 整板 **全图共 9 格不多不少**；模式 A 单场景多机位 + A 档「仅允许摄影机移动」；50mm 统一参数；5 个子区域；每格右下角机位编号 + 标注降级条款。

* **道具四格**：2×2 整板（正面 / 45° 侧 / 俯视 / 细节特写）；**左上角标注道具名**（道具图保留标注）；**禁手禁人禁剪影**。

* 资产板统一 `doubao-seedream-5-0-pro`、16:9。

### P4・投喂提示词（每段一段 `### 段N · 标题`）



* 段数 ≈ 8 段、总时长 ≤ 120s、**每段 ≤ 15s、每段时码从 00:00 起**（禁累计时码）；段号靠标题区分。

* 每段七段式字段：


  * `【画幅风格】9:16 竖屏，{年代/题材背景}，电影级写实·{影调}·5500K 冷光·{主色}（model=seedance-2.0）`

  * `【场景资产】@//scn/ - 名（图N，母版+九宫格双挂）；@//prp/ - 名（图K，外观以道具参考图锁定，状态：初态→末态）；时段光影：…`

  * `【核心人物】@//chr/ - 名（图N，声线锁：英文标签）`—— 画面 / 动作行（△）角色用**全名**，对白行内可用简称

  * `【站位声明】@名（位置·朝向·动作）；轴线锁定：…，全段禁越轴`

  * `【时间轴分镜】- 00:00-00:0X [镜头N] 景别·焦段·机位角度·运镜（用途标签）。画面主体：…。声音：…。台词：无 或 谁（情绪·语速）："…"`

  * `【音效】环境音列举（默认模型生成）`

  * `【强制禁止项】画面：禁字幕、禁水印（含Logo）；音频：禁背景音乐，仅环境音与人声`

* 每段围栏后附一份**未编译纯镜行副本**（`---` 分隔，便于直接投喂）。



***

## 四、编译



```
python "{技能目录}\scripts\build_board_lite.py" "{输出目录}\{项目名}_第{集号}集_看板源.md" --out "{输出目录}\{项目名}_第{集号}集_投喂看板.html" --export-json "{输出目录}\{项目名}_第{集号}集_画布载荷.json" --asset-ledger "{输出目录}"
```



***

## 五、校验（读 JSON，逐项核对）



1. `canvas_contract.schema` = `drama-canvas-feed/v2`，`video_model` = `doubao-seedance-2-0`；

2. `asset_ledger` 项数 = 历史台账 + 本集新增（**复用资产不重复导出**）；

3. `asset_prompts` 只含**本集新增**资产，每项带 `kind`（character/scene/prop）与 `assetId`；**所有对白角色的完整英文音色定义必须写入顶层 `voice_prompts`，复用角色不得省略**；

4. 每段 `【音色引用】@音频｜角色（图N）` **只对有对白角色生成**（纯动作段无）；

5. 编译输出 `WARN：0`。



***

## 六、交付

`present_files` 交付三件套，命名：`{项目名}_第{集号}集_看板源.md` / `{项目名}_第{集号}集_投喂看板.html` / `{项目名}_第{集号}集_画布载荷.json`。汇报：段数 / 镜数 / 总时长 / WARN、新增资产清单、台账项数。



***

## 红线



1. **只生成文件**；未经用户明确指令，禁止提交任何花钱生成（出图 / 视频 API）；资产生成前必须先问 "生成"；

2. 剧本没读全不落笔；锁值没问清不动手（冷启动）；

3. 台词逐字照剧本，不改写剧情；△ 行角色全名、对白行内简称；

4. 投喂稿 @CHR 出现名单与实挂 URL 集合必须一致（挂接核对铁律）—— 提交生成前执行；

5. 同剧连续集同一画幅 / 模型 / 风格锁值，**不混档**；标题不带版本备注；

6. 技能升级后按该环境的三端（开发 / 源 / 生效）技能目录同步，MD5 一致才算完成，并跳过缓存目录（如 `__pycache__`）。

# 05 · 前端交互与操作流程

## 1. 入口与形态

### 入口

- 画布右下角悬浮按钮：**“与 AI 对话”**（与截图一致）。
- 顶部工具栏可选入口：**“智能体”**（与项目设置同级）。
- 两个入口打开同一个 `AgentDock`；记住上次打开状态。

### 形态

- 右侧浮层，宽 420–560px，可拖宽；不挤压画布，不改变画布 viewport。
- 可折叠为一条 44px 侧边条；折叠后画布完全不受影响。
- 移动端：全屏底部抽屉（90% 高度），可下滑关闭。
- 与画布同时操作：允许；导入时用 revision 校验，不锁画布。

> 关键：**AgentDock 不放进 CanvasView 组件树**，避免把 129 个 state 的画布和 Agent 状态耦合。挂在 `main.tsx` 的画布容器旁。

## 2. 面板结构

~~~text
┌──────────────────────────────┐
│ 智能体   [技能: 漫剧老李 ▾]  [×] │
│ 项目：铁西硬汉 · EP007         │
├──────────────────────────────┤
│ [对话/时间线]                  │
│  你：做一集 90 秒重生复仇…      │
│  Agent：先确认 7 个锁…         │
│  ┌ 锁题卡：赛道/来源/模型… ┐   │
│  └──────────────────────────┘   │
│  步骤 1/6 · 剧本 ✓             │
│  步骤 2/6 · 资产 ✓             │
│  步骤 3/6 · 分镜 …             │
│  ┌ 产物：投喂稿（feed.json）┐   │
│  │ 预检通过 · 3 条警告       │   │
│  │ [预览] [下载] [导入画布]  │   │
│  └──────────────────────────┘   │
├──────────────────────────────┤
│ [输入框]                [发送] │
│ 当前模型：…  预算：…           │
└──────────────────────────────┘
~~~

### 顶部

- 技能选择器：默认上次使用；可切套件/子技能；显示版本与契约状态（绿色“v2 兼容”/红色“不兼容”）。
- 项目/集：只读显示；导入目标在预览里确认。
- 运行状态：排队/进行中/等你选择/待审/导入中/完成/失败。

### 消息区

- 用户/Agent 气泡；Agent 的“思考”折叠，不刷屏。
- 步骤时间线：每步可展开工具调用摘要（不显示 API key）。
- 锁题卡：分组、选项、多选/单选、推荐项、确认。
- 产物卡：类型、大小、校验状态、预览/下载。
- 系统提示：不把内部错误堆栈直接给用户；给可行动作。

### 底部输入

- 第一版不做命令系统；技能用选择器。
- 第一版只读项目上下文；不把 @ 当画布引用。
- 发送前显示模型/预算；超预算需确认。

## 3. 核心流程

### 3.1 从一句创意到画布（新建集）

0. 新会话空态展示“技能快捷片”：剧本开发 / 创作分镜 / 视频拆解 / 全流程导演（点击即选中对应技能并预填输入）。
1. 打开 AgentDock，选“漫剧老李 V7.4.29”。
2. 输入：“做一集 90 秒重生复仇短剧，Seedance 2.5，竖屏”。
3. Agent 推送锁题卡（按技能要求）：
   - 赛道：国内剧/海外剧/解说/其他
   - 素材来源：原创/改编/对标/热点
   - 模型：Seedance 2.5 / 2.0 / H3
   - 画幅：16:9 / 9:16 / 21:9
   - 交付形态：离线看板 / md / 两者
   - 段缝：末帧定格 / 硬切 / 空镜 / 技巧转场
   - 画风：候选卡（推荐项 + 自定义）
4. 用户逐项选择；Agent 复述锁结果并开始。
5. 时间线推进：剧本 → 资产 → 分镜 → 投喂稿；每步可展开细节。
6. 产出 `feed.json`；自动预检；显示“通过/警告/错误”。
7. 点“导入画布” → 预览：新增节点/连线、复用资产、警告、目标集。
8. 确认 → 调用现有导入；成功后 toast“已导入 EP009 · 23 节点”；按钮“在画布中查看”。
9. 画布刷新由 `setCanvasEpoch` 完成；不自动打开节点弹窗。

### 3.2 追加/修订现有集

- 用户在创建运行前选“追加到现有集”，或在预览里改目标集。
- 必须二次确认“会与现有集合并，资产按 series/variant 复用”。
- 预览展示 diff；现有 reimport policy 生效。

### 3.3 只修一段/一角色

- 用户选中某个 artifact/段，输入“只改第 3 段，别动其他”。
- Agent 生成新 feed 时保留其余段；预检对比段数/角色数，防止“修一段丢全片”。
- 若必须重写，先提示影响范围。

### 3.4 校验失败

- 错误列表按 `segment/role/code` 分组；每条给“定位到 JSON”/“让 Agent 修”。
- “让 Agent 修”最多 2 轮（MVP 先 1 轮）；每轮显示修了什么。
- 第二轮仍失败：显示“下载 JSON 手动修改”与“取消”；不允许导入。
- 不允许 Agent 静默删除失败段。

### 3.5 运行历史

- 项目内列出最近运行：时间、技能、状态、集、导入结果。
- 可“继续/复制运行/查看产物/重新导入”。
- 运行中关闭面板不取消任务；重新打开可接上 SSE。

## 4. 锁题卡设计

锁题是技能的硬门，UI 必须让用户**明确选择**，不能默认跳过。

~~~text
┌ 选择赛道 ─────────────────────┐
│ ○ 国内剧   ○ 海外剧           │
│ ○ 解说叙事 ○ 其他             │
│ 说明：影响剧本/分镜规则        │
│                  [确认]        │
└───────────────────────────────┘
~~~

规则：

- 单选/多选由 `question.multi` 决定；选项可带描述。
- 必须选完才允许“继续”；“按推荐”只能作为显式选项，不默认。
- 已回答的锁显示为摘要 chip，可展开修改（修改会提示下游重跑）。
- 锁结果写入 run input，后续阶段引用；不重复问。
- 画风锁支持候选卡（缩略图/风格词/推荐），而不是纯文本。

## 5. 产物审阅

### 5.1 产物类型

| 类型 | 展示 | 操作 |
|---|---|---|
| `brief` | Markdown 渲染 | 复制/下载 |
| `script` | Markdown | 复制/下载 |
| `assets` | 资产表（图号/语义码/名称/复用） | 筛选/复制 |
| `storyboard` | 分镜表/故事板说明 | 复制/下载 |
| `feed` | JSON 树 + 原文 | 校验/下载/导入 |

### 5.2 feed 预览

- 顶部：schema/契约 hash/生成时间/技能版本/模型。
- 校验徽标：通过（绿）/警告（黄）/错误（红）。
- 错误/警告列表：code、message、path、segment、role；点击定位 JSON 行/段。
- JSON 查看器：折叠树 + 原文切换；只读；支持复制/下载。
- 导入预览：新增/更新/复用节点/连线、目标集、revision、警告。
- 底部：**取消** / **下载 JSON** / **导入画布**（主按钮）。

### 5.3 导入确认

文案示例：

> 将导入到 **第09集 · 重生复仇**：新增 23 个节点、41 条连线，复用 6 个资产。
> 当前项目 revision 13275；导入后会生成快照，可在“项目版本”回滚。
> 有 2 条警告（不影响导入）。

按钮：取消 / 确认导入。

成功后：

> 已导入第09集：23 节点 / 41 连线 / 复用 6 个资产。
> [在画布中查看]

## 6. 技能库

入口：设置 → 智能体 → 技能库；或 AgentDock 顶部“管理技能”。

### 列表

- 技能卡：名称、版本、套件/单技能、契约状态、文件数、大小、启用状态、上传者/时间。
- 操作：查看详情、激活/回滚、禁用、删除（软删）。
- “官方/内置”标识；用户上传包单独标识。

### 上传向导

1. 选择 zip（≤50MB）。
2. 上传 + 校验（进度/阶段：解压、manifest、契约 hash、入口、安全）。
3. 校验报告：通过项/警告/错误；错误不可激活。
4. 预览：名称/版本/技能数/入口/权限。
5. 激活：明确“新运行使用该版本；历史运行不受影响”。

### 详情

- 入口 `SKILL.md` 预览（Markdown 安全渲染）。
- 版本列表 + 契约 hash。
- 权限清单（读项目/读资产/写产物/执行脚本/联网）。
- 最近使用运行。

## 7. 异常与空状态

| 状态 | 展示 | 动作 |
|---|---|---|
| 未选项目 | “先选择/新建项目” | 打开项目选择 |
| 无技能 | “还没有技能包” | 去技能库/上传 |
| 技能不兼容 | “该技能产出的契约与当前画布不一致” | 查看详情/换版本 |
| 模型不可用 | “当前模型不可用” | 换模型/检查设置 |
| 排队 | “排队中 · 前面 N 个” | 取消 |
| 超时 | “运行超时，已保留产物” | 继续/重试/下载 |
| 校验失败 | 错误列表 | 让 Agent 修/下载 |
| revision 冲突 | “项目已更新，已重新预检” | 再看预览/重试 |
| 预算超限 | “预计超出预算” | 调预算/取消 |
| 只读分享 | “只读模式不能运行智能体” | 关闭 |

空状态文案要具体，不写“出错了”。

## 8. 多标签页、只读、移动端

- **多标签页**：run 在服务端；另一标签页打开同一项目可看到活跃 run（只读）；默认不允许同一项目两个并发 run。
- **只读分享**：隐藏 Agent 入口；直接访问 API 返回 403。
- **移动端**：底部抽屉全屏；锁题卡纵向排列；产物 JSON 用可横向滚动代码块；导入确认大按钮。
- **弱网**：SSE 自动重连；断线时显示“正在重连”，不丢 run；产物仍需服务端确认。

---

## 9. 无障碍与细节

- 面板 `role="complementary"`，标题/状态用 `aria-live="polite"`。
- 所有图标按钮有 `aria-label`；锁题单选组用 `role="radiogroup"`。
- 键盘：Esc 关闭面板；Tab 焦点陷阱；发送 Ctrl+Enter。
- 触控目标 ≥ 32px（现有画布 15px 版本箭头是反例，不要复制）。
- 尊重 `prefers-reduced-motion`；流式文本不做逐字动画时可关闭。
- 颜色不单独承载状态（绿/黄/红同时配文字/图标）。

---

## 10. 与画布的交互约定

- 打开/关闭 Agent 面板不改变画布选中、viewport、缩放。
- 导入成功后：刷新项目数据、切到目标集、toast 提示；**不自动打开节点弹窗**。
- 用户正在拖拽/框选时，面板不抢焦点。
- Agent 运行中画布仍可编辑；导入时 revision 冲突就重检，不覆盖。
- 画布“与 AI 对话”按钮不替代现有“生成”按钮；两条路径并存。
